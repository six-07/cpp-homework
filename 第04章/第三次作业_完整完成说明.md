## 4.15 Sales Commission Calculator

### a) Read the problem statement

销售员每周固定工资为 **200 美元**，另加当周总销售额的 **9%**。程序要使用 `while` 语句逐名读取销售员的销售额，计算并显示该销售员的周工资，输入 `-1` 时结束。

计算公式：

```text
salary = 200 + grossSales × 0.09
```

例如：

```text
5000 × 0.09 = 450
200 + 450 = 650
```

### b) Pseudocode and top-down, stepwise refinement

#### 第 1 层：总体任务

```text
Prompt for and read the first salesperson's gross sales
WHILE the sales amount is not the sentinel -1
    Determine that salesperson's salary
    Display the salary
    Prompt for and read the next salesperson's gross sales
ENDWHILE
```

#### 第 2 层：细化变量和计算

```text
SET baseSalary = 200.00
SET commissionRate = 0.09

DISPLAY "Enter sales in dollars (-1 to end): "
INPUT grossSales

WHILE grossSales != -1
    SET salary = baseSalary + grossSales * commissionRate
    DISPLAY "Salary is: $", salary with 2 decimal places

    DISPLAY "Enter sales in dollars (-1 to end): "
    INPUT grossSales
ENDWHILE
```

#### 第 3 层：补充输入有效性检查

```text
SET baseSalary = 200.00
SET commissionRate = 0.09

DISPLAY "Enter sales in dollars (-1 to end): "
INPUT grossSales

WHILE input is valid AND grossSales != -1
    IF grossSales >= 0 THEN
        SET salary = baseSalary + grossSales * commissionRate
        DISPLAY "Salary is: $", salary with 2 decimal places
    ELSE
        DISPLAY "Sales cannot be negative."
    ENDIF

    DISPLAY "Enter sales in dollars (-1 to end): "
    INPUT grossSales
ENDWHILE
```

完整伪代码文件：`第04章/04_15_sales_commission_calculator_pseudocode.md`

### c) C++ program

源文件：`第04章/04_15_sales_commission_calculator.cpp`

程序使用 `while (cin >> grossSales && grossSales != -1.0)` 实现逐名处理，使用 `fixed` 和 `setprecision(2)` 把工资显示为两位小数。

### d) Test, debug, and execute

编译命令：

```powershell
g++ .\第04章\04_15_sales_commission_calculator.cpp -o .\build\04_15_sales_commission_calculator.exe -std=c++11 -Wall -Wextra -pedantic -static
```

## 4.33 Sides of a Right Triangle

要求：读取三个非零整数，判断它们能否作为直角三角形的三条边。

源文件：`第04章/04_33_right_triangle.cpp`

实现方式：找出最长边，然后检查是否符合勾股定理：

```text
largestSide² = otherSide1² + otherSide2²
```

测试结果：

| 输入 | 输出 |
| --- | --- |
| `3 4 5` | 是直角三角形的三条边 |
| `5 13 12` | 是直角三角形的三条边（输入顺序不影响结果） |
| `2 3 4` | 不是直角三角形的三条边 |
| `0 3 4` | 提示三边必须为非零整数 |

## 4.27 Printing the Decimal Equivalent of a Binary Number

要求：输入一个只含 `0` 和 `1` 的整数，使用取余和除法从右向左取位，计算对应的十进制数。

源文件：`第04章/04_27_binary_to_decimal.cpp`

计算方式是依次使用位权 `1、2、4、8……` 累加：

```text
1101 = 1×1 + 0×2 + 1×4 + 1×8 = 13
```

测试结果：

| 输入 | 输出 |
| --- | --- |
| `1101` | `13` |
| `101010` | `42` |
| `0` | `0` |
| `1021` | 提示输入只能包含 `0` 和 `1` |
